Published Claude Skills, a personal marketplace of Claude Code skills for the pull request workflow. `/pr-review` runs AI-assisted reviews that check GraphQL and Prisma contracts, `/pr-respond` works through review comments, and `/push` runs a quality-gated push pipeline.

The skills detect frontend and backend stacks on their own, so they work in any project with no per-project config.
