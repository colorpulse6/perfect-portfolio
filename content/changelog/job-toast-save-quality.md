Improved how Job Toast reads a posting when an assistant saves its URL. The save result now explains where the description came from and whether recovery has been queued, so a saved job and a complete posting are easier to tell apart.

I checked the extraction paths against a set of reference postings and improved the page-reading fallback. The aim is to keep the useful job text with the application, and make incomplete saves visible.
