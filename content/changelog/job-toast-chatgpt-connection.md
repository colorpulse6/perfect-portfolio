Added the first version of Job Toast's ChatGPT connection. It exposes saved jobs, work-profile context, application status and cover-letter drafting through MCP, the protocol assistants use to call tools.

The connection uses account sign-in and explicit consent. This was the start of the assistant integration, with connection fixes and support for more clients following afterward. It does not submit applications on employer sites.
